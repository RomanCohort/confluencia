【选择路径】

----------------------------------------------------------------
路径A: 上传到云GPU运行完整版（推荐）
----------------------------------------------------------------

需要: 云GPU服务器SSH访问权限

步骤1: 上传部署包
  打开Git Bash或PowerShell:
  
  cd D:/IGEM集成方案
  
  # 替换YOUR_SERVER为你的云GPU地址
  scp deploy_package.tar.gz pipeline_code.tar.gz root@YOUR_SERVER:/root/

步骤2: 连接云GPU
  ssh root@YOUR_SERVER

步骤3: 解压并验证
  cd /root
  tar -xzf deploy_package.tar.gz
  tar -xzf pipeline_code.tar.gz -C deploy_package/circrna_3d_pipeline/
  
  cd deploy_package
  python verify_dependencies.py

步骤4: 安装缺失依赖（如有）
  conda install -c bioconda viennarna -y
  conda install -c conda-forge openmm -y
  pip install ray pyyaml numpy pandas

步骤5: 安装RoseTTAFold2NA（Stage 2必需）
  git clone https://github.com/baker-laboratory/RoseTTAFold2NA.git
  cd RoseTTAFold2NA
  wget https://files.ipd.uw.edu/public/RoseTTAFold2NA/RoseTTAFold2NA_weights.tar.gz
  tar -xzf RoseTTAFold2NA_weights.tar.gz -C weights/
  cd ..

步骤6: 准备输入数据
  # 生成测试序列（10条）
  python << 'PYEOF'
import random
bases = ['A', 'C', 'G', 'U']
with open("test.fasta", 'w') as f:
    for i in range(10):
        L = random.randint(80, 150)
        seq = ''.join(random.choices(bases, k=L))
        f.write(f">circ_test_{i:03d} length={L} bsj_start=0 bsj_end={L}\n{seq}\n")
PYEOF

步骤7: 运行完整Pipeline
  chmod +x deploy_full_pipeline.sh
  ./deploy_full_pipeline.sh test.fasta

步骤8: 检查结果
  cat output_*/dataset_report.json
  ls output_*/seq_*/cyclized/*.pdb
