## 三个 Core 验证点（按优先级排序）

### 验证点 1：dsRNA 连续段 vs 免疫原性
**问题**：V3 假设"长 dsRNA → MDA5 激活 → 高免疫原性"，但这个因果链需要实验证实。

**低成本验证方案（4周）：**
```
步骤1: 体外转录 circRNA（无修饰 / m6A 修饰 / Ψ 修饰各5条）
步骤2: Agarose 凝胶电泳 + UV 定量 → 粗测环化效率
步骤3: SHAPE-MaP 预实验（1条序列校准 TorusFold 预测）
步骤4: DC 细胞混合实验（IFN-β ELISA，检测免疫原性）
```

**关键指标**：
- `dsRNA_fraction` vs `IFN-β` 相关性（预期正相关，p<0.05）
- `long_dsRNA_frac_500bp` vs `MDA5` 信号强度（预期强相关）

**高成本验证（可选，8-12周）：**
- qPCR 检测体内表达量
- 流式细胞术检测 CD8+ T 细胞活化

---

### 验证点 2：分段权重有效性
**问题**：V3 的分段权重函数是否比 V2 线性权重更优？

**基准测试集（15个已知样本）：**
| 样本 | 特征 | 来源 |
|------|------|------|
| cIRB-001 | 未修饰，低免疫原性 | Wesselhoeft 2018 |
| cIRB-m6A | m6A 修饰，中免疫原性 | Chen 2019 |
| cIRB-Ψ | Ψ 修饰，预期无效 | 璩良 2026 |
| BSJ-mut | BSJ 突变，翻译失败 | Liang 2022 |
| ... | ... | ... |

**评估指标**：
- ROC-AUC（V2 vs V3 对已知样本的预测准确率）
- 帕累托前沿覆盖度（V2 vs V3 四维目标空间分布）

---

### 验证点 3：Ψ 修饰在 circRNA 中禁用
**问题**：复旦璩良 2026 工作声称 Ψ 破坏 IRES 环化，但这是否是普遍规律？

**快速验证（2周）：**
```python
# STEPS 骨架环化实验
from experiments.validation import run_steps_assay
result = run_steps_assay(sequence="ACGU...", modification="Psi")
print(f"环化效率: {result['circulation_rate']}%")  # 预期 <5%
```

**关键判断标准**：
- 如果 `circulation_rate < 5%` → 确认 Ψ 禁用
- 如果 `circulation_rate > 50%` → 说明 BSJ 位置或序列背景影响

## 可证伪性检验清单

每个验证点都有明确的"通过/不通过"标准：

### 验证点 1 通过标准
- [ ] dsRNA_fraction 与 IFN-β 显著正相关（R² > 0.7）
- [ ] long_dsRNA_frac_500bp 是最优预测因子（vs 裸 fraction）
- [ ] V3 预测准确率 > V2（ROC-AUC 提升 > 0.05）

### 验证点 2 通过标准
- [ ] V3 对 15 个已知样本的预测误差 < V2（MAE 降低 > 20%）
- [ ] V3 帕累托前沿包含更多 Pareto-optimal 解

### 验证点 3 通过标准
- [ ] Ψ 修饰组环化效率 < 5%（vs 对照 > 50%）
- [ ] m6A 修饰组半衰期延长 > 2倍
