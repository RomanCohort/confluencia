\begin{abstract}
\textbf{Summary:} No specialized tool exists for circRNA drug evaluation because the field lacks public PK datasets and clinical endpoint standards. Confluencia addresses this gap with literature-constrained pharmacokinetic modeling (RNACTM, half-life validated within 4.1\%), sample-size-adaptive MOE ensemble (39.2\% MAE reduction at $N{=}300$), and uncertainty-adaptive five-dimension scoring that downweights under-constrained dimensions via $(1-u)^2$ penalty. Cross-module reasoning produces Go/Conditional/No-Go recommendations that individual tools cannot---e.g., $\Psi$ extends half-life but raises immunogenicity risk.\\
\textbf{Availability and implementation:} \url{https://github.com/RomanCohort/confluencia}, MIT license. Python 3.8+, Linux/macOS/Windows.\\
\textbf{Contact:} \email{18806370529@163.com}
\end{abstract}
