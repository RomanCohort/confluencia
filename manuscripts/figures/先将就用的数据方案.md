```

$k_{ab}=0.80$/h (absorption), $k_{be}=0.025$/h (endosomal uptake),

$k_{cp}=0.02-0.32$/h (translation, IRES-dependent), 
$k_{cd}=0.04-0.12$/h (degradation, borrowed from Wesselhoeft 2018 and RNA Biology 2024).
```

### Methods Module 3修改
```
\textbf{Differential m6A Suppression (Conservative Estimates).} 
m6A modification suppresses immune activation with pathway-specific intensity. 
These values are conservative literature-derived estimates:
\begin{itemize}
\item MDA5/dsRNA: 70\% suppression (Chen 2019 immunogenicity reduction, adjusted for pathway specificity)
\item TLR7/8: 20\% suppression (Gilleron 2013 endosomal environment, m6A less effective here)
\item PKR: 10\% suppression (Nallagatla 2007 PKR responds to dsRNA length, not sequence modifications)
\end{itemize}
```
