\section*{Availability and Implementation}

Confluencia v2.5.0 is freely available at \url{https://github.com/RomanCohort/confluencia} under MIT license. Implemented in Python 3.8+ using scikit-learn \citep{pedregosa2011}, RDKit, NumPy, and Streamlit---no GPU or cloud infrastructure required; all modules run on consumer hardware (full evaluation $<$5\,min on a standard laptop). Both a Streamlit web interface and a desktop IDE (Confluencia Studio, Electron+React, RStudio-like layout) provide graphical access to all functions without programming, enabling direct use by wet-lab researchers. Runs on Linux, macOS, and Windows with optional Docker deployment. Confluencia is actively used in our circRNA therapeutic development pipeline at the First Bethune Hospital of Jilin University. Benchmark datasets and all experimental results are available in the repository's benchmarks directory.
