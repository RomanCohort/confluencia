\section{Introduction}

Therapeutic circRNA offers advantages over linear mRNA in stability and tunable immunogenicity \citep{wesselhoeft2018,chen2019}, yet no platform evaluates circRNA-specific dimensions: modification effects on half-life ($\Psi$: ${\sim}15$\,h vs unmodified: 6.24\,h), circRNA immunogenicity pathways, IRES-mediated translation, or miRNA sponge activity. Existing tools address individual modalities, including NetMHCpan \citep{reynisson2020}, ADMETlab \citep{xiong2024}, and Monolix \citep{dumont2014}, but none operates across small-molecule and circRNA modalities.

For early-stage candidate screening, accessibility outweighs marginal accuracy. A tool that runs on any laptop without GPU payment has greater field impact than one marginally more accurate but inaccessible to most labs, particularly student teams like iGEM. We developed Confluencia to integrate these evaluations with this accessibility-first principle, producing Go/Conditional/No-Go decisions. Three design choices address the data-limited setting (Fig~\ref{fig:overview}): (1) RNACTM, a literature-parameterized compartment simulation for circRNA dynamics (RNACTM provides compartment dynamics for candidate comparison, not clinical trial simulation); (2) sample-size-adaptive weighted model averaging (WMA; inverse-RMSE weighting, a stacking simplification) for binding prediction; (3) uncertainty-adaptive 4D evaluation auto-downweighting under-constrained dimensions via $(1{-}u)^2$.

\paragraph{Ecosystem for collaborative improvement.}
In addition to core prediction, Confluencia provides infrastructure for community-driven model refinement: (1) \textbf{Confluencia Studio}, an Electron+React desktop IDE integrating Streamlit-based interfaces for visual candidate evaluation; (2) \textbf{Confluencia Hub}, an offline-first federated model sharing system where users contribute trained model bundles without exposing raw SMILES/sequence data, addressing data privacy concerns that hinder pharmaceutical collaboration; (3) \textbf{Open training pipelines} enabling the DBTL Learn stage: contributors can retrain drug/epitope models on local data and push improved weights to the community pool. This allows Confluencia to improve as the community contributes new models and data.
