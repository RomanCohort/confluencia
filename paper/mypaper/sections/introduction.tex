\section{Introduction}

Therapeutic circRNA offers advantages over linear mRNA in stability and tunable immunogenicity \citep{wesselhoeft2018,chen2019}. Yet circRNA--drug pair evaluation requires reasoning across two modalities---small-molecule pharmacology (ADMET, MHC binding) and circRNA dynamics (half-life, immunogenicity, TME)---a cross-modality assessment no existing tool provides. NetMHCpan handles MHC binding \citep{reynisson2020} but ignores circRNA; ADMETlab covers toxicity \citep{xiong2024} but lacks circRNA PK; population PK software cannot model nucleotide modification effects ($\Psi$: ${\sim}15$\,h vs unmodified: 6.24\,h). Each tool operates in a single-modality silo, missing critical interplays---e.g., $\Psi$ extends half-life but raises immunogenicity risk.

Confluencia bridges this gap with an architecture evaluating both modalities: (1) RNACTM, a six-compartment ODE model for circRNA PK; (2) sample-size-adaptive Mixture-of-Experts \citep{jacobs1991} for drug binding; (3) uncertainty-adaptive five-dimension evaluation yielding integrated Go/Conditional/No-Go recommendations.
