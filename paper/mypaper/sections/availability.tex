\section*{Availability and Implementation}

Confluencia v2.6.0: \url{https://github.com/IGEM-FBH/confluencia}, MIT license. Python 3.8+; no GPU for core evaluation (compartment simulation, immunogenicity, 5D, MOE); GPU optional for sequence embeddings. Three interfaces: GUI IDE, R package (27 functions via \texttt{devtools::install\_github()}), VS Code extension (11 commands with PK webviews and 5D score tree). Python discovery: \texttt{cf\_use\_python()} / \texttt{cf\_find\_python()}. Core evaluation $<$5\,min on laptop. Hub: offline-first model sharing. Linux/macOS/Windows.
