\section{Discussion}

Confluencia evaluates circRNA-specific dimensions absent from existing platforms and implements a DBTL \emph{architecture}: 5D evaluation (Design), RNACTM configuration (Build), simulation and assays (Test), open training pipelines (Learn; accessible but not yet exercised with independent data).

Three computational validations: (1) immunogenicity direction consistency with literature IFN data ($\rho{=}0.93$); (2) 5D decisions stable under weight perturbation; (3) gene signature stratification ($p{<}0.001$). All are computational, not wet-lab; in-house experiments will provide independent benchmarks.

RNACTM half-life consistency is by design (parametrization verification, not prediction); the 17\% expression window deviation is the informative metric. RNACTM is deterministic, not population PK---its value is integrating circRNA-specific dimensions that Monolix does not address. Drug binding achieves R$^2{=}0.95$ but efficacy only R$^2{=}0.60$; removing Morgan fingerprints improves binding R$^2$ 0.67$\to$0.95, validating sample-size-adaptive design. MHC (AUC 0.80) underperforms NetMHCpan (0.92--0.96); focused-repertoire alleles are comparable, common alleles remain challenging. Immunogenicity weights are heuristic; direction-consistency verifies ranking, not quantitative accuracy.

Limitations: (1) miRNA/RBP/translation lack evaluation ($u{=}0.8$, effective weight $\sim$4\%); (2) no inter-individual variability; (3) heuristic immunogenicity weights; (4) DBTL Learn awaits experimental data. Three interfaces (GUI, R 27 functions, VS Code 11 commands) share one Python backend, with Hub sharing and plugin extensibility.
